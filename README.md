# level82.dev

The LEVEL82 website, published with GitHub Pages at https://level82.dev (static files, no build step).

| Path | Page |
|---|---|
| `leeroy/privacy/` | Leeroy! privacy policy (English, linked from Google Play) |
| `leeroy/privacy/it/` | Leeroy! privacy policy (Italian) |

The privacy pages are copies of `store/privacy.en.html` and `store/privacy.it.html` in the Leeroy! repository, where a test checks them; change them there and copy them here.

`CNAME` holds the custom domain for GitHub Pages; `.nojekyll` serves the files as they are.
